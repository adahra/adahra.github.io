# Repository Guidelines

## Project Overview
Static personal website (Adahra website) for Adnanto A.R. Generated by Hugo 0.73.0. Hosted on GitHub Pages at `adahra.github.io`. The repository contains only the built static output — no Hugo source, content, or build tooling is present.

## Architecture & Data Flow
- Pure static site: HTML pages generated by Hugo, served as-is by GitHub Pages.
- No server-side code, no build scripts, no package manifest in this repo.
- `dist/` contains hashed CSS/JS assets (TACHYONS v4.9.1 + a small JS bundle), indicating the original Hugo project used a bundler (e.g., webpack) — but the source project lives elsewhere.
- Content flow (external): Hugo source (content/, layouts/, config.toml) → `hugo` build → this repo → GitHub Pages.

## Key Directories
- `/` – Root HTML pages: `index.html` (homepage), `404.html`, `index.xml` (RSS), `sitemap.xml`
- `/posts/` – Blog posts (e.g., `my-first-post/index.html`), `posts/index.html` listing, `posts/index.xml` feed
- `/categories/` – Category listing page + RSS feed
- `/tags/` – Tag listing page + RSS feed
- `/images/` – Media assets (e.g., `gohugo-default-sample-hero-image.jpg`)
- `/dist/css/` – Minified TACHYONS CSS bundles (4 hashed files)
- `/dist/js/` – JavaScript bundle (1 hashed file)

## Development Commands
No build commands exist in this repo. To regenerate the site, use the external Hugo project. If you need to build locally:
```bash
hugo --minify   # assumed; config not present here
```

## Code Conventions & Common Patterns
- HTML5 with semantic structure (`<header>`, `<main>`, `<footer>`, `<section>`)
- TACHYONS CSS utility classes (e.g., `ma0 avenir bg-near-white`, `pa3`, `w-100`)
- RSS feeds (`index.xml`) and sitemap.xml for SEO
- Open Graph and Twitter Card meta tags in each page
- GPL v2 license header in hand-edited files (e.g., `index.html`)

## Important Files
- `index.html` – Homepage (hand-edited; includes inline styles, personal info, contact links)
- `posts/my-first-post/index.html` – Example blog post
- `dist/css/app.*.css` – TACHYONS minified CSS
- `dist/js/app.*.js` – JavaScript bundle (webpack-style module wrapper)
- `index.xml`, `posts/index.xml`, `categories/index.xml`, `tags/index.xml` – RSS feeds
- `sitemap.xml` – Search engine sitemap
- `404.html` – Custom 404 page

## Runtime/Tooling Preferences
- Hugo 0.73.0 (static site generator) — source project external to this repo
- TACHYONS v4.9.1 (CSS framework)
- GitHub Pages (hosting)
- No package manager, no CI, no lockfiles, no Dockerfile, no Makefile

## Testing & QA
No tests, no CI configuration, no test frameworks. QA would involve manually verifying generated HTML/CSS/JS output and checking for accessibility/SEO correctness.
