About Me

Where code meets curiosity

A journey from Linux tinkering to shipping production Flutter apps used by thousands

It started with a dusty ThinkPad and a desire to understand how things work under the hood. Late nights compiling kernels, breaking package managers, and learning that sudo rm -rf / is not a troubleshooting step. That Linux mindset—curiosity, resilience, obsession with clean systems—became the foundation of how I write code today.

Fast forward to 2020: I discovered Flutter. The promise of a single codebase for mobile, web, and desktop felt like the Unix philosophy applied to UI—write once, run everywhere, compose small tools. I've since shipped apps for fintech, health-tech, and developer tooling, each teaching me something new about performance, architecture, and the art of saying "no" to unnecessary complexity.

When I'm not writing Dart, you'll find me contributing to open source, optimizing CI pipelines, or diving into Flutter's rendering engine to understand why that frame dropped. I believe great software is invisible—it just works.
